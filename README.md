# Conway's Game of Life —— verilog implementation

>This is a course's final project, which requires designing a meaningful sequential circuit based on a FPGA board.

The repository gives a verilog implementation of "Conway's Game of Life".

You may need a Vivado to run and test the codes, import the modules to a project → run simulation → generate bitstream → program on the board.

- Check for source code from /src;
- Check for simulation code from /sim;
- Check for detailed explanation from /documents;
- Write the constraints based on your own board.
